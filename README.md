# Jarvis AI for Android

A fresh Android assistant project for Fynn. The starter app is designed to include spoken replies, speech-to-text input, simple local memory, and a GitHub Actions workflow that builds a debug APK.

## Build an APK
1. Open the Actions tab.
2. Select Build Jarvis APK.
3. Tap Run workflow if it has not run automatically.
4. Open the completed run and download the jarvis-debug-apk artifact.

Hands-free wake-word detection and full AI service integration are follow-up features; this starter does not claim reliable always-listening wake-word support yet.
